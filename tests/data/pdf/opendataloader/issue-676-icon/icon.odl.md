The upload page shows the state of each file that you send to the server. If the upload fails, click the [Retry button](https://example.com/retry) ![](<icon_images/imageFile1.png>) to start the upload again. The page also gives the size of each file and the time of the upload.

Each test writes a report at the end of the run. The report gives the time, the number of the checks, and the result of each check. Keep the reports of the last month, so that you can compare the results of two runs.

Before you start

- Read all the steps first.
- Put the parts on a table.
- Keep the parts dry.


While you work

- Turn off the power.
- Use the tools of the box.
- Do not use force.


- Check that no part is lost.
- Clean the table.
- Find the tools.


- Work in a dry room.
- Keep the cover closed.
- Stop if you see smoke.
